## Key Architecture Decisions & Constraints

- **DOM injection:** Do not use `container.innerHTML += ...` for complex dynamic trees (menu loops). It re-parses the subtree, drops listeners, and yields `null` on mobile. Use `insertAdjacentHTML('beforeend', ...)` or `document.createElement`.
- **Unique-string patches:** Prefer Python unique-string replace on `index.html` over brittle search/replace in the 200KB file. Avoid `print(...)` with escaped quotes in those scripts (parse errors abort the whole patch).
- **SQ API (`API_REFERENCE.md`):** Reverse-engineered map of `https://inflightmenu.singaporeair.com` → unauthenticated `POST https://cifp.auto.prod.c0.singaporeair.com/api/{getcabin|menu}`. No key; `sessionId` is local. CORS: preflight `*`, POST allowlist is the official origin only — JSON must stay on `/api/sq`; **do not** call cifp from the browser. Images are `<img src>` to `https://inflightmenu.singaporeair.com/…` (not CORS-gated). Dish photos: `imagePathIfeHigh` on ~9% of items (relative `fabs/IFE/INFM/<cabin>/HIGH|LOW/<id>_<cabin>.png`); otherwise construct from item `id` (`DH021259-v3-FCL` → strip `-vN` → `DH021259_FCL.png`). Missing CDN objects return **HTTP 200 + `index.html`**, so `onerror` (decode fail) is the miss signal — never trust status. Amenity `imagePath` is relative (`ifss/images/…`, encode spaces). `highResImagePath` / `lowResImagePath` on selections are empty in production. `getcabin` → `cabinClasses` (+ `101` unpublished). `/menu` → `legs[]` (each leg is a full menu world), `menu.language.EN_UK.meals`, beverages, amenities. Multi-leg: one `/menu` returns all legs; `flightDate` is the first leg. Proxy timeout in `api/sq.js` is 12s.
- **Vercel proxy:** SQ WAF is aggressive. The live app still `POST`s `/api/sq` (`getcabin` / `menu` only). Do not add a browser cifp client. `api/getcabin.ts`, `api/menu.ts`, and `api/cabins.ts` are leftover extra routes if present; do not replace `/api/sq` without changing the frontend contract.
- **Design system:** Glass (`glass-bubble`, `glass-sheet`). Palette: SIA Navy `#0B1A3A`, Charcoal, SIA Gold `#C9A227`. Mobile-first iOS styling.
- **Chat cadence (project rule):** After every chat bubble (user or bot, including calculator and lookup cards) fully animates in, wait 500ms before showing another bubble or the typing indicator. Do not start typing until that gap has elapsed. Typing may be followed immediately by the next bot bubble once typing hides. Do not let the user send a message or press chat/chip/lookup buttons until the on-screen bubbles have fully displayed (prevents spamming).
- **SemVer (project rule):** Keep `APP_VERSION` in `index.html` and paint it on onboarding as `vX.Y.Z` (`#app-semver`, very low contrast). Bump it on **every** change: patch (x.y.Z) for fixes/copy/polish, minor (x.Y.0) for features, major (X.0.0) for breaking product shifts. Current line is 1.x (stable crew app: chat, COP, menu, printer). This stamp is how the user confirms the phone is on the latest build.
- **Cache:** Bump `CACHE_NAME` in `sw.js` when `index.html` (or other cached assets) change.
- **Continuity:** After every commit, update `README.md` and `HANDOVER.md` to match the build. Ask for review before starting the next slice of work.
- **Sandbox drift:** This environment can silently check out old `main` (`a70877c`) with mass deletions. Recover with `git fetch origin arena/01a0819d-crewassist` + `git reset --hard FETCH_HEAD`. Only push to the arena branch. Merging arena → main in GitHub Desktop is correct.
